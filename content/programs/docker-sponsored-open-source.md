## What it is

The Docker-Sponsored Open Source (DSOS) program supports non-commercial open source projects that publish images on Docker Hub.

## What you can use it for

Running your project's Docker workflow without rate limits. Docker lists a verified Docker-Sponsored Open Source badge, repository logos, insights and analytics, Docker Scout on up to 100 repositories, unlimited pulls and egress for people pulling your public images, and a free one-year Docker Team subscription for core contributors, which covers Docker Desktop, 15 concurrent autobuilds, unlimited vulnerability scans, role-based access control and audit logs.

## Who qualifies

The project namespace must be shared in public repositories with public source code, meet the Open Source Initiative definition, be in active development on Docker Hub (image or dependency updates within the past 6 months), and have no pathway to commercialization. Accepting donations is allowed. Benefits go only to project leads and core committers, and licenses cannot be shared with third parties.

Status and benefits last one year and can be renewed if the project still meets the requirements.

## How to apply

1. Check your project against the criteria on docker.com/community/open-source/application.
2. Submit the application form on that page.
3. Renew each year while the project still qualifies.
