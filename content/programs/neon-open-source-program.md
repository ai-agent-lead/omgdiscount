## What it is

Neon sponsors open source maintainers with monthly cash payments through GitHub Sponsors, paid from a pool Neon says is at least $200,000 a year. Sponsored projects can also take optional Neon and AI Gateway credits.

## What you can use it for

The cash sponsorship supports maintenance of your open source project. The optional credits, up to $5,000 on Neon and $5,000 on Neon AI Gateway, can be used if you want to build on Neon. Your project does not need to use Neon or Postgres to apply.

## Who qualifies

The project must have a public repository under an OSI-approved open source license, be in active development, and have GitHub Sponsors enabled on the repository or maintainer. Commercial open source can qualify if developers can self-host it and the sponsorship supports the open source project.

Neon sets the monthly cash amount during review; that amount is not published in advance. Sponsorships run for a six-month term and do not renew automatically. In return, you show the Neon logo, labeled as a sponsorship, in one agreed place for the full term.

Check neon.com/programs/open-source for the current terms.

## How to apply

1. Enable GitHub Sponsors on the repository or maintainer profile if it is not already active.
2. Fill out the application on neon.com/programs/open-source with your project's website and GitHub repository.
3. Neon follows up by email. If you are accepted, set up payouts in GitHub Sponsors and, if you want them, use any Neon or AI Gateway credits you are offered.
