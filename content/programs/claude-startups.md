## What it is

Claude Startups is Anthropic's program for early-stage founders building on Claude. Members get partner offers, Applied AI sessions and events. As of 10 November 2026, the official page says the current cohort is full and Anthropic is not accepting new applications.

## What you can use it for

The Claude Startup Stack is a set of discounts and credits, worth up to $45,000, from AI-native companies building with Claude, across sales, design, data, meetings and engineering. Members redeem each offer with a code in the Claude Console. Members can also join live group sessions with Anthropic's Applied AI team every other week, and Claude Startup events, hackathons and meetups.

Founders backed by a VC in Anthropic's partner network may be eligible for up to $100,000 in additional API credits, claimed through the VC. Program credits apply only to the first-party Claude API in the Claude Console, not to AWS, Google Cloud, Azure or other third-party platforms.

## Who qualifies

The program is for early-stage founders building on Claude. The official page no longer lists a public application form. Interest was higher than expected, and the current cohort is full. The program continues for current members. Anthropic encourages people who were not accepted to apply when the next cohort opens, and to subscribe to the Claude Startup newsletter for that date.

Check claude.com/programs/startups for the current status.

## How to apply

1. Open claude.com/programs/startups. If applications are still closed, you cannot submit a new request.
2. Subscribe to the Claude Startup newsletter on that page to hear when the next cohort opens.
3. If you are already a member, keep using the Claude Startups portal and Console codes; membership is continuing for the current cohort.
