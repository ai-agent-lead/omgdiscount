## What it is

GitHub for Startups gives partner-affiliated startups $10,000 in credits to use across the GitHub Enterprise platform for up to 12 months.

## What you can use it for

The credits go toward your GitHub Enterprise license costs and eligible add-ons, including GitHub Copilot, GitHub Advanced Security and GitHub Actions. GitHub says credits are applied only to the Enterprise account you submit in your application.

## Who qualifies

GitHub says eligible startups must be affiliated with a GitHub for Startups partner, have received outside funding (Series B or earlier), and be new to GitHub Enterprise, meaning no Enterprise plan in the past six months. Startups that have previously received GitHub credits or Enterprise licenses are not eligible.

Check github.com/enterprise/startups for the current terms.

## How to apply

1. Confirm your investor, incubator or accelerator is a GitHub for Startups partner.
2. Apply through that partner on github.com/enterprise/startups.
3. Credits are applied to the Enterprise account you submit.
