## What it is

The GitHub Student Developer Pack is GitHub Education's bundle of tools and offers from GitHub and its partners, made for students who would otherwise find professional tools too expensive.

## What you can use it for

Learning and building projects with a code editor, cloud, database and monitoring stack at no cost. Examples listed on the pack page include GitHub Copilot Student (unlimited code completions and an allowance of GitHub AI Credits, with limited chat and agent usage), GitHub Codespaces at Pro level, a free annual JetBrains subscription, $13 USD per month of Heroku credit for 24 months, $50 in MongoDB Atlas credits, Datadog Pro with 10 servers for 2 years, $25 in Stripe credits and 1Password free for 2 years.

## Who qualifies

The pack is for verified students. Each partner sets its own offer and length, and the list changes over time, so check each offer before relying on it.

Check education.github.com/pack for the current list.

## How to apply

1. Open education.github.com/pack and sign in with your GitHub account.
2. Verify your student status through GitHub Education.
3. Claim the partner offers you want from the pack page.
