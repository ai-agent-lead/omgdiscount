## What it is

Convex sponsors open source developers building tools, frameworks and apps in its ecosystem, and offers accepted projects free Convex Pro, support and swag.

## What you can use it for

Running the project on Convex Pro for one team, within the built-in monthly Pro resource limits, with direct access to the Convex team and developer community.

## Who qualifies

Your project should be actively maintained and fully open source, built with Convex or planning to integrate it, and should support the developer ecosystem through tools, libraries or resources. Nonprofits can apply if the codebase is open and maintained.

If you are building a startup, Convex says you are still eligible when the software is open source, and points funded companies toward the separate Startups Program. Convex reviews applications on a rolling basis and says it responds within 60 days. A README link back to Convex is not required.

Check convex.dev/open-source-program for the current terms. The page does not publish a dollar value or a fixed term length.

## How to apply

1. Open convex.dev/open-source-program and start the application for credits.
2. Describe the project, how it uses or will use Convex, and how it supports the ecosystem.
3. Wait for a decision. Convex says reviews are rolling and a response can take up to 60 days. If accepted, use Pro on one team within the built-in limits.
