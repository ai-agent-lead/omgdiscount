## What it is

Amazon Web Services: servers, serverless functions, storage and Bedrock for models.

## What you can use it for

Backend hosting, queues, file storage, and running model endpoints.

## Who qualifies

Founders tier is for self-funded startups that have not received Activate credits before, with a working website and a founding date within the last 10 years.

Portfolio tier is for startups backed by an Activate Provider (a VC fund or accelerator on AWS's list). You need that provider's Organization ID. The provider sets the amount, so $200,000 is a ceiling, not a guarantee.

An AI tier above $200,000 is invitation-only.

## How to apply

1. Open aws.amazon.com/startups and choose Founders or Portfolio.
2. For Portfolio, enter your provider's Organization ID.
3. Submit the application with your company website and workload description.
4. After approval, redeem the credit code in the AWS Billing console before it expires.
