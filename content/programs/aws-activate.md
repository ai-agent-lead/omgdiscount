## What it is

Amazon Web Services: servers, serverless functions, storage and Bedrock for models.

## What you can use it for

Backend hosting, queues, file storage, and running model endpoints.

## Who qualifies

Founders tier is for self-funded startups that have not used Activate credits before.

Portfolio tier is for startups backed by an Activate Provider and needs that provider's Organization ID. The provider sets the amount, so $200,000 is a ceiling.

## How to apply

1. Open aws.amazon.com/startups and choose Founders or Portfolio.
2. For Portfolio, enter your provider's Organization ID.
3. After approval, redeem the credit code in the AWS Billing console before it expires.
