## What it is

JetBrains has two open source routes. Individual contributors and small or early-stage projects can use JetBrains IDEs for free for personal, non-commercial open source development, with no application or approval process. Established open source projects with an active development lifecycle and broad impact on the developer community can request complimentary All Products Pack subscriptions, and each application is reviewed individually.

## What you can use it for

Developing your open source project. The licenses must be used only for non-commercial open source development.

## Who qualifies

For the All Products Pack, the request form says you should be a project lead or a core contributor. Licenses are granted only to active contributors whose contributions are regular and visible in the repository; non-code commits are not considered active development. You confirm the licenses will be used only for non-commercial open source development and shared only with the project's active contributors. If you use GitHub, the project's activity is checked automatically when you submit the form. The page does not publish the licence term length or a project count.

Check jetbrains.com/community/opensource for the current terms.

## How to apply

1. For the free non-commercial IDEs, download the IDE from JetBrains and start coding; no application is needed.
2. For the All Products Pack, fill out the request form at jetbrains.com/shop/eform/opensource as a project lead or core contributor.
3. Provide the project name, website, repository URL and a copy of the license terms for your software, plus any previous JetBrains open source license ID.
