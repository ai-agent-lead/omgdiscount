## What it is

Render lets you deploy some service types at no charge: web services, Render Postgres, Render Key Value and static sites, by choosing the Free compute plan.

## What you can use it for

Previewing the platform, hobby projects and testing. Each workspace gets 750 Free instance hours per month for web services. Static sites and web services also count against included outbound bandwidth and build pipeline minutes.

## Who qualifies

Anyone with a Render account can create Free instances. Render says not to use them for production. Free web services spin down after 15 minutes without traffic and take about a minute to start again. Free Postgres is limited to one instance per workspace, 1 GB of storage, and expires 30 days after creation, with a 14-day grace period to upgrade. Free Key Value is limited to one in-memory instance per workspace, and data is lost on restart.

Hours reset each calendar month and do not roll over. If you use all 750 hours, Free web services are suspended until the next month.

Check render.com/docs/free for the current limits.

## How to apply

1. Sign up at render.com if you do not already have an account.
2. In the dashboard, create a Static Site, Web Service, Postgres or Key Value instance and choose the Free compute plan.
3. Watch Monthly Included Usage on the Billing page, and upgrade a service to a paid plan if you need production limits.
