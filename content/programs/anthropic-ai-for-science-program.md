## What it is

Anthropic's AI for Science Program gives free Claude API credits to researchers in academia and nonprofit organizations who are applying generative AI to scientific work Anthropic considers high priority, especially in biology and the life sciences.

## What you can use it for

The credits apply to Anthropic's standard, publicly available Claude models through the API. They cannot be used on the Claude web app, and the program does not include non-public models or fine-tuning. Recipients are still bound by Anthropic's usage policy.

## Who qualifies

The help center says the program is for researchers attached to research institutions, working on high-impact scientific projects. Supported fields include biology, chemistry, medicine, environmental science, physics, computer science, earth sciences and other work with significant scientific potential, with particular interest in life-sciences applications.

Anthropic evaluates submissions on the first Monday of each month. If approved, up to $20,000 in API credits is applied to your account for six months. Unapproved applicants may not receive an individual response.

Check the program page on the Claude Help Center for the current terms and application form.

## How to apply

1. Read the program description at support.claude.com/en/articles/11199177-anthropic-s-ai-for-science-program.
2. Complete the application form linked from that page, with details about your team and research project. Multi-researcher labs should apply from a single organization account.
3. Wait for the next monthly review. If approved, use the API credits within the six-month period.
