## What it is

Vercel offers a Pro trial so you can try Pro features at no charge. The trial includes a $20 credit and lasts 14 days or until you hit the trial usage limits, whichever comes first.

## What you can use it for

Exploring Pro team features and usage, including the $20 credit, which also covers on-demand Observability Plus events during the trial. Some Pro features are excluded, including Drains, account webhooks, the free first-year domain, and Sandbox failover regions.

## Who qualifies

Each user account can start one Pro trial. Official trial caps include 1 owner, up to 10 team members, 200 projects, 16 CPU-hours, 1,440 GB-hours of provisioned memory and 1 million function invocations per month. The trial pauses if Active CPU, provisioned memory or function invocations reach 100% of those limits.

You are not charged if you do not add a payment method; the team reverts to Hobby when the trial ends. Billing starts when the trial ends only if a payment method is on file.

Check vercel.com/docs/plans/pro-plan/trials for the current terms.

## How to apply

1. In the Vercel dashboard, create a new team.
2. Choose the Pro Trial option. If it does not appear, you have already used your one trial.
3. Use the $20 credit within 14 days. Add a payment method before the trial ends if you want to stay on Pro; otherwise the team returns to Hobby.
